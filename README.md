# QB Evaluator

Grades NFL QBs 1-100 using nflverse play-by-play + FTN charting, separating interceptions by fault
(bad throw vs. tipped/receiver-caused, plus "dropped interceptions"). Methodology is backtested
before anything is adopted; see the Methodology page in the app or `qb_backtest.ipynb` for the numbers.

## Files
- `qb_eval.py` - data loading, counterfactual value models, play-level adjustments, QB tables, 1-100 grade
- `backtest.py` - split-half and year-over-year tests, bootstrap CIs, shrinkage
- `mixed.py` - play-level QB + defense + offense effects model (ridge = random effects)
- `qb_backtest.ipynb` - the full backtest analysis (executed); generated by `make_notebook.py`
- `update_board.py` - weekly live-board refresh (no backtests); see "Weekly refresh" below
- `app.py` - the Streamlit site (leaderboard, QB pages, methodology)
- `boards/` - committed snapshots `update_board.py` writes and `app.py` reads; nothing else touches the network

## Run the backtest notebook
    python -m venv .venv
    source .venv/Scripts/activate   # Git Bash on Windows (PowerShell: .venv\Scripts\activate)
    pip install -r requirements.txt
    jupyter nbconvert --execute --to notebook --inplace qb_backtest.ipynb

First run downloads historical seasons into `data/` (cached after that; gitignored).

## Run the app locally
    streamlit run app.py

`app.py` reads only `boards/` and makes no network calls of its own -- it won't fail or hang if
nflverse/nflreadpy is unreachable. To see real data locally you need `boards/` populated first
(already committed for the current season; see below to refresh it or add another season).

## Weekly refresh
    python update_board.py [--season 2026] [--qualifier-per-game 14]

Fits the model on 2022-2025, applies it to `--season`, and writes one cumulative and one
single-week board per fully-completed week (a week in progress is skipped) plus an interceptions
file, all under `boards/`. In production this runs on a schedule -- see
`.github/workflows/update_board.yml` and "Weekly refresh" in `CLAUDE.md` for how it's wired up and
how to trigger it manually.

## Deploying the app
The app is built to deploy on Streamlit Community Cloud with no secrets and no extra
configuration: point it at this repo, `app.py` as the entrypoint, and it reads `boards/` directly
from the checked-out repo. `runtime.txt` pins the Python version Community Cloud builds with.
